# Agent notes

## Typography

Visible copy uses curly quotes and apostrophes. That includes page text, Markdown prose, captions, alt text, button labels, and similar strings readers see.

- Apostrophes and elisions: `’` (U+2019), including contractions (`Don’t`) and clipped words (`’em`)
- Quoted phrases: `“` and `”` (U+201C and U+201D)

Straight `'` and `"` stay in code, markup, URLs, and fenced or commented commands.
