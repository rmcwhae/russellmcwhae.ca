# AGENTS.md

## Setup commands

- Install deps: `pnpm install`
- Start dev server: `pnpm dev`
- Run tests: `pnpm test`

## Code style

- TypeScript strict mode
- Single quotes, no semicolons
- Use functional patterns where possible
- In written text, markdown files and inline HTML words, prefer curly quotes (“”‘’) over straight quotes and apostrophes ("')
